## Reglas visuales aplicadas

- Formato 4:5, 1080×1350, con las primeras tres láminas funcionando como entrada, contexto y tensión.
- Una idea principal por lámina; titulares grandes y lectura clara desde teléfono.
- Micro-infografías y anotaciones de dominio: libro de gates, frontera señal/evidencia y trazabilidad de fuentes.
- Color acompañado por texto y etiquetas; el color nunca es la única forma de comunicar estado.
- Sin fotografía de stock ni imagen generada: la evidencia del caso es el elemento visual principal.
- Las afirmaciones visibles mantienen `[VERIFIED]`, `[PUBLIC SIGNAL]` y `[UNKNOWN]`.
