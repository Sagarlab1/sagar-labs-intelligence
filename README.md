# Sagar Intelligence

Official multi-route web experience for Sagar Intelligence.

## Local development

The project uses the Sites-compatible Next.js runtime, React, TypeScript, Tailwind CSS, Framer Motion, Three.js and Lucide.

```bash
npm install
npm run dev
```
