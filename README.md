# Sagar Labs — Experience OS Beta

Private beta of the bilingual enterprise experience for Sagar Labs Decision Intelligence.

## Local development

The project uses the Sites-compatible Next.js runtime, React, TypeScript, Tailwind CSS, Framer Motion, Three.js and Lucide.

```bash
npm install
npm run dev
```
